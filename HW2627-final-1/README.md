# Финальное задание. Основы Go

Десять небольших программ на Go: условия, циклы, функции и арифметические операции.
Для каждого задания отдельная папка, все данные вводятся с клавиатуры.

## Запуск

```bash
cd HW2627-final-1
go run ./task1
```

Можно запускать и по файлу:

```bash
go run task1/main.go
```

После результата программа спрашивает `Повторить? (д/н)`: `д` — ввести новые данные, любой другой ответ — выход.
В задании 9 вместо этого меню с пунктом `0 - выход`.

## Задания

1. `task1` — калькулятор: два числа и операция `+`, `-`, `*`, `/`, проверка деления на ноль.
2. `task2` — анализ числа: знак, чётность, делимость на 3 и на 5.
3. `task3` — сумма и среднее значение чисел от 1 до N.
4. `task4` — таблица умножения числа от 1 до 10, вывод через функцию `printTable`.
5. `task5` — максимальное и минимальное из N введённых чисел.
6. `task6` — количество положительных, отрицательных чисел и нулей.
7. `task7` — сумма чисел от 1 до N, которые делятся на 2 и на 3.
8. `task8` — проверка, является ли число простым (функция `isPrime`).
9. `task9` — мини-банкомат: просмотр баланса, пополнение, снятие с проверкой остатка.
10. `task10` — статистика последовательности: сумма, среднее, максимум, минимум, чётные и нечётные.

## Примеры

Задание 1:

```text
Введите первое число: 7.5
Введите операцию (+ - * /): /
Введите второе число: 2.5
Результат: 3.00
Повторить? (д/н): н
```

Задание 9:

```text
Введите начальный баланс: 1000

1 - посмотреть баланс
2 - пополнить баланс
3 - снять средства
0 - выход
Выберите действие: 2
Сумма пополнения: 500
Баланс пополнен. Текущий баланс: 1500.00
```
